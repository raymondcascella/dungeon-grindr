# Dungeon Grindr

A swipe-based dungeon crawler card game. Single HTML file, no build step, no dependencies.

## Play

Open `dungeon-grindr.html` in any modern browser. Works offline after the first load.

## How it works

Swipe right to engage, left to flee or skip. Build a party of up to 3 adventurers, fight through 3 floors, kill the boss.

- **Recruit phase** — swipe through 12 classes, pick your party
- **Dungeon phase** — each floor is a deck of monsters, treasures, events, and potions
- **Combat** — each party member draws 1 action card per round; pick one to play, the monster telegraphs its move last

## What's in the box

- 12 classes, each with a unique 5-card combat deck
- 11 monsters across 3 tiers + 3 bosses
- 7 treasure types, 8 random events, 4 potions
- 3 floors with escalating difficulty
- Randomly generated class-flavored names for recruits each run

## Stack

Vanilla JS, no framework, no build tools. About 2,200 lines of HTML/CSS/JS in a single file.
